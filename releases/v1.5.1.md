# Ocean 1.5.1 — Refresh shortcut for coral layouts

Version **1.5.1 / code 24** replaces the camera icon beside **Set wallpaper**
with a Refresh icon. Tap it to choose a different one of four prepared coral
layouts immediately. The existing **Redistribute corals** option in **Corals &
clams** still works. This changes only the saved layout; your species choices,
appearance settings and camera angle stay as they were.

Camera gestures still work in Ocean's app preview. For reset, rotation and pan
sliders or precise zoom, open **Settings > Camera** (`Einstellungen > Kamera
einstellen`). Camera edits still reach the active wallpaper only after you
confirm **Set wallpaper** in Android's system picker.

The Refresh symbol is original vector UI art. The reef models, four prepared
layouts, five clams and species portraits are unchanged. Existing asset origins
and license terms remain in [Third-Party Notices](https://github.com/ShakieVan/Ocean-LiveWallpaper/blob/main/THIRD_PARTY_NOTICES.md).

Three targeted Android UI tests passed. The signed app opened with the new
Refresh icon and retained **Settings > Camera**. Update through **Settings >
Updates** (`Einstellungen > Updates`). These emulator checks do not establish
phone battery or performance behavior.
