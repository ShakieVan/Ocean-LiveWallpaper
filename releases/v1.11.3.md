# Ocean 1.11.3 — Responsive parallax depth tracking and resilient sensor registration

Ocean 1.11.3 makes tilt/parallax camera tracking significantly more immediate and resilient across sensor delivery modes:

- **Responsive parallax depth tracking:**
  - **Rate-matched camera smoothing:** Replaces the fixed 200 ms low-pass filter (`5.0 1/s`) with filter rates matched to the selected **Expert / Energy > Tilt response** stage (`28.0 1/s` / ~36 ms time constant on *fast*, `14.0 1/s` / ~71 ms on *normal*, and `5.0 1/s` / 200 ms on *power-saving*), cutting 90% response latency on *fast* from ~460 ms to ~82 ms so the reef stays locked to device tilt like a window into a 3D aquarium.
  - **Higher angular sensitivity within safe frustum bounds:** Increases tilt angle gain from `2.0` to `3.2` so full parallax excursion is reached at a natural ~18° wrist tilt instead of requiring ~29°, while keeping the maximum camera orbit envelope unchanged.
- **Resilient sensor registration:**
  - **Automatic rate and sensor fallback:** Checks the `SensorManager.registerListener` result when activating or switching tilt response rates and automatically falls back from `SENSOR_DELAY_GAME` to `SENSOR_DELAY_UI` / `SENSOR_DELAY_NORMAL` (and from `TYPE_GAME_ROTATION_VECTOR` to `TYPE_ROTATION_VECTOR`) if a rate is rejected, preventing tilt from silently deactivating when switching to *fast*.
  - **High-sampling sensor permission declaration:** Declares the install-time `android.permission.HIGH_SAMPLING_RATE_SENSORS` permission for Android 12+ sensor rate queries.

Update through **Settings > Updates**, or download the universal APK from the [1.11.3 release](https://github.com/ShakieVan/Ocean-LiveWallpaper/releases/tag/v1.11.3).
