# Ocean 1.24.1 (Beta) — Preparing Ocean's own signing key

Ocean 1.24.1 (Beta) changes nothing you can see. It prepares the next version, which is signed with Ocean's own release key instead of the general Android development key used so far:

- **Key handover:** the updater accepts a new version signed with a new key when the current key has handed Ocean over to it (key rotation of Android's APK Signature Scheme v3). Android's installer follows the same rule, so the update keeps your settings and needs no uninstall. Versions signed with an unknown key are still refused.
- **Newest release:** the updater now reads the list of releases and takes the newest valid version, even when another release is marked "Latest" on GitHub.
- **Checks again right after an update:** the first time you open Ocean after an update, it looks for a newer version at once instead of waiting a day.

1.24.1 itself is still signed with the previous key, so the updater of 1.24.0 and older accepts it. For that reason it stays marked "Latest" on GitHub; 1.24.2, the first version with the new key, follows right after it and is offered by 1.24.1 at once.

## Known limits

- Checked on an API-36 Android emulator, not on phones and not on Android 9 to 12.
- The lock screen itself was not looked at. This is a beta.

Update through **Settings > Updates**, or download the universal APK from the [1.24.1 Beta release](https://github.com/ShakieVan/Ocean-LiveWallpaper/releases/tag/v1.24.1).
