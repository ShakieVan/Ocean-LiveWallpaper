# Ocean 1.0.0

- Eight detailed fish types, articulated fins and responsive small schools.
- A coral canyon with underwater light, vegetation and a rock tunnel.
- Saved camera position, rotation and zoom.
- New clownfish launcher icon.
- GitHub updates with file-integrity and signing-identity checks.
- A fixed battery measurement display for the whole device in Settings.

Android 9 or newer. Updates keep your settings when installed over the existing
app with the same signing identity. No silent installation or background
update checks in the wallpaper service.

See the [current installation status](https://github.com/ShakieVan/Ocean-LiveWallpaper/blob/main/INSTALLATION.md#google-play-protect)
and [third-party notices](https://github.com/ShakieVan/Ocean-LiveWallpaper/blob/main/THIRD_PARTY_NOTICES.md).
