# Ocean 1.8.3 — Rendering efficiency

This update reduces unnecessary work while retaining the existing lighting,
caustic movement, soft shadows, textures and scene detail.

- Water lighting reuses wave calculations and evaluates the same wave shape
  with fewer expensive operations.
- Rendering follows the display's reported refresh rate and the selected
  30/40/50/60 FPS target. When the graphics queue is busy, unnecessary scene
  uploads are skipped while movement continues.
- Scene shaders are prepared ahead of use, texture transfers are grouped,
  and fish route checks exclude clearly distant obstacles earlier.

All existing settings are preserved. No resolution, shadow-quality or fish-count
reduction is applied. Update through **Settings > Updates**, or download the
universal APK from the [1.8.3 release](https://github.com/ShakieVan/Ocean-LiveWallpaper/releases/tag/v1.8.3).

Native emulator comparisons retain the appearance of all eight fish species
and the moving light. Small numerical rounding differences remain in some lit
pixels; this is not a claim of complete pixel identity. Scripted fish movement
matches the previous version exactly in the tested scenarios.

The signed release passed four system previews beside an active wallpaper,
returning to the app and screen off/on, with both lighting options enabled.
No crash or ANR was observed in that run. Phone frame-rate and battery gains
have not been measured. The earlier emulator graphics stalls reported with
1.8.2 remain an unresolved historical finding; this release does not establish
that their cause or every phone stutter has been fixed.

Version **1.8.3 / code 31**. Existing Android system controls continue to determine
which home-screen and lock-screen wallpaper destinations are available.
