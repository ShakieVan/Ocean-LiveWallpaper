# Ocean 1.0.3

> [!NOTE]
> Play Protect blocked this version during an emulator test. The cause remains
> unknown. An appeal was submitted on September 13, 2026; Google confirmed receipt,
> but has not communicated a decision. This is not a confirmed false positive.
> [Installation guide with screenshots](https://github.com/ShakieVan/Ocean-LiveWallpaper/blob/main/INSTALLATION.md#google-play-protect).

The unchanged APK's [VirusTotal scan](https://www.virustotal.com/gui/file/4591edc13eeb30c1aeaca974bb541c8e6b026a1593933678c6c7cd28ed3ab172)
reported **0/67 detections** on September 13. This is not a safety guarantee or
Play Protect clearance. No APK bytes were changed by this documentation update.

This update tests the in-app update flow. Only the version numbers changed from
1.0.2; the reef, fish, settings and renderer are unchanged.

Open **Settings > Updates** to check the available version. The installation-permission
shortcut opens Ocean's Android settings. After an update, a reminder offers to
open those settings again if the permission is still active.

Download `Ocean-1.0.3-universal.apk` below. The MP4 is a short app preview, not an
installation file. Source-code ZIP/TAR entries contain public documentation only.
